# Stas Web Design — сайт-визитка и демо-сайты

Главная (`index.html`) — сайт-визитка: работы, дизайн под ниши, зачем сайт, цены, этапы, управление сайтом, вопросы, форма заявки. `projects/` — страница «Все проекты». Общие стили в `assets/site.css`, список проектов в `assets/projects.js`. Демо — отдельные папки с `index.html`, адрес: `https://staswebdesign.github.io/<папка>/`. Демо закрыты от поисковиков (`noindex`).

## Как добавить проект в «Работы»
1. Положите скриншот первого экрана 16:10 в `works/`, например `works/p-name.jpg`.
2. Добавьте строку в `assets/projects.js` (название, ссылка, картинка, тип, описание). Первые 4 проекта видны на главной, все — на странице `/projects/`.

## Как добавить или обновить демо через браузер
1. Откройте репозиторий → **Add file → Upload files**.
2. Перетащите папку клиента (внутри `index.html`).
3. Нажмите **Commit changes**. Через 1–2 минуты сайт обновится по той же ссылке.

## Логотип
Папка `brand/`: знак (`mark-*.svg`), иконки-плитки (`icon-*.svg`, `icon-lime-1024.png`), горизонтальный и вертикальный логотип (`logo-*.svg`, текст переведён в кривые), фавиконки. Основной вариант: тёмная плитка, светлая S, лаймовая точка (`icon-dark-2color.svg`, `icon-main-1024.png`, `logo-main-*`). Цвета: лайм `#D7FF3B`, графит `#0d0d0c`, светлый `#f3f1ea`. Шрифты: Manrope ExtraBold, JetBrains Mono.
